# 🧠 Logic Building in C

A daily-practice repository where I build programming logic in **C**. New programs are pushed regularly, starting from the basics and growing towards Data Structures & Algorithms (DSA) and projects in C.

> **Goal:** Think in logic first, write code second. Consistency over intensity.

**Author:** Dhumal Jaydeep Machhindra

---

## 📌 About This Repository

- Programs written in **C**, pushed daily
- Every program follows a clear problem-solving process, not just code
- Clean, readable and well-documented code
- Covers C fundamentals, DSA concepts and C projects

---

## 🧩 How I Solve Every Problem

Each program follows the same 5 steps, written as comments inside the code:

1. **Understand** the problem statement
2. **Write the algorithm** (START → steps → END)
3. **Decide the programming language** (C)
4. **Write the program**
5. **Test the program** using a table of test cases (positive, negative and zero inputs)

---

## ✍️ Coding Standards I Follow

- **Naming convention:** variables are prefixed with their type, e.g. `iValue1`, `iResult`
- **Function header comments:** name, input, output, description, date and author
- **Inline comments** for parameters and business logic
- **Initialize variables** before using them
- **`EXIT_SUCCESS`** (from `<stdlib.h>`) as the return value of `main`
- **Test cases** written at the end of every program

## ⚙️ How to Run

**1. Clone the repository**
```bash
git clone https://github.com/Jai-dhumal/logic-building-in-c.git
cd logic-building-in-c
```

**2. Compile with GCC**
```bash
gcc filename.c -o output
```

**3. Run**
```bash
./output          # Linux / macOS
output.exe        # Windows
```
